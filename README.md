# RINGSIDE 로컬 웹사이트

## 실행
Node.js 22.13 이상(검증: Node 24.5)이 설치된 Mac에서 start.command를 실행하거나 이 폴더에서 `node server.mjs`를 실행합니다. npm install 없이 실행됩니다.
접속: http://127.0.0.1:4173
현재는 해당 컴퓨터에서 사용하는 로컬 버전입니다. Firebase 배포는 하지 않았습니다.
브라우저의 React 모듈과 폰트는 CDN에서 읽으므로 처음 화면을 열 때 인터넷 연결이 필요합니다.

## 관리자
화면의 운영자 모드에서 요청한 관리자 비밀번호로 로그인하세요. 새 설치에도 동일한 초기 비밀번호가 적용됩니다. admin-bootstrap.json에는 비밀번호의 scrypt 해시만 포함되며 브라우저에 제공되지 않습니다. 회원 관리에서 비밀번호를 변경할 수 있습니다.
압축 파일에는 기존 사용자 계정·투표·업로드 데이터가 포함되지 않습니다.

## 기능
닉네임/비밀번호 가입과 로그인, 가입 시 100 응원 포인트, 계정당 경기별 1표, 지지율/언더독, 경기 추가, 투표 마감, 결과 발표, 개인 예측 기록.
3라운드×70초 타이머: 시작/정지/재개/다음 라운드/초기화. 시작하면 투표 마감. 다음 라운드는 현재 라운드가 0초일 때 가능.
사진: JPG, PNG, WebP. 영상: MP4, WebM. 파일당 100MB. 운영자 데스크에서 포스터/선수 사진/경기 영상을 첨부하면 미디어 화면에 표시됩니다. 업로드 파일과 DB는 data/에 지속 저장됩니다.
전재신 vs 오승민 경기 정보가 기본 등록되어 있습니다. 첨부 원본 포스터를 내려받지 못하여 기본 그래픽을 사용했습니다. 관리자에서 원본 사진을 선택해 교체할 수 있습니다.

## 검증
가입/로그인, 중복 투표 차단, 관리자 제한, 경기 시작 후 투표 차단, CSRF 출처 검사, 이미지 파일 업로드/연결/부분 조회, 위장 파일 거부, 재시작 후 데이터 유지 API 테스트 통과. 실제 브라우저 메인 화면과 관리자 로그인·업로드 폼 확인.
단위/통합 검사: `node --test tests/*.test.mjs`
사용자 데이터가 생성되는 data/를 삭제하지 마세요. 공용 인터넷 배포 시 HTTPS, 저장소/운영 보안 검토가 별도로 필요합니다.

## 관리자 편집
경기 제목·선수·장소·시간·규칙 수정, 경기 보관/복원, 결과 취소, 사진·영상 교체/제거, 개별 투표 삭제/전체 초기화, 회원 이름·포인트·비밀번호·사용 중지, 사이트 소개 수정, 라운드/남은 시간 직접 설정을 지원합니다. 관리자 권한은 서버에서 검사합니다.
